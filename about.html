The root interface of the collection hierarchy. The Collection interface extends the Iterable interface and therefore all the subclasses of Collection interface also implement the Iterable interface. The Collection interface is the interface which is implemented by all the classes in the collection framework. It declares the methods that every collection will have. In other words, we can say that the Collection interface builds the foundation on which the collection framework depends.
